# Курсовая работа

Тема: **дедупликация словаря на основе DSU и расстояния Левенштейна**.

Идея взята из моего проекта: https://github.com/kleget/english_project. Там похожая логика была в `algo_cleaner` и `algo_DSU`, но здесь оставлена только минимальная часть для курсовой.

## Файлы

- `deduplicator.py` - алгоритм.
- `main.py` - простой графический интерфейс.
- `sample_words.txt` - пример входных данных.

## Запуск

```bash
cd sem4/coursavaya
python main.py
```

## Формат данных

Можно вставлять обычный текст или словарь:

```text
algorithm 7
algoritm 2
banana 4
bananna 1
```

## Как работает алгоритм

1. Программа получает слова и считает их частоты.
2. Для слов создается DSU - структура непересекающихся множеств.
3. Слова сравниваются только с кандидатами похожей длины и одинаковым префиксом.
4. Если расстояние Левенштейна не больше порога, слова объединяются через `union`.
5. В каждой группе главным становится самое частотное слово.
6. Частоты похожих слов складываются.

## Что такое DSU

DSU хранит набор непересекающихся множеств.

- `find(x)` возвращает представителя множества.
- `union(a, b)` объединяет два множества.

В задаче множество - это группа похожих слов.

## Что такое расстояние Левенштейна

Это минимальное количество операций вставки, удаления и замены символа, чтобы превратить одно слово в другое.

Пример: `algoritm` и `algorithm` отличаются на одну вставку, расстояние равно `1`.

## Сложность

Полный перебор всех пар слов имеет сложность `O(n^2)`. Здесь сравнений меньше, потому что слова заранее группируются по длине и префиксу. В худшем случае все равно возможен `O(n^2)`, но на обычном словаре работает быстрее.
