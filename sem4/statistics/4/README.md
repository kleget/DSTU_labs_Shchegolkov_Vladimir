# Практическая работа: байесовский анализ и вероятностное программирование

В папке лежит готовая работа по указанным страницам из двух книг:

- **Байесовский анализ на Python**: страницы 35–41, 101–114, 118–127, 157–175.
- **Вероятностное программирование на Python**: страницы 62–94 и 231–249.

Код сделан в одном файле `src/run_all.py`. Он использует `numpy`, `pandas`, `scipy`, `matplotlib`, `scikit-learn` и `statsmodels`. Основная логика намеренно простая: данные читаются таблицами, параметры считаются понятными функциями, графики сохраняются в `plots/`, числовые итоги — в `results/`.

## Как запустить

```bash
pip install -r requirements.txt
python src/run_all.py
```

После запуска появятся:

- `plots/*.png` — все графики;
- `results/*.csv` — таблицы с итогами;
- `data/*.csv` — использованные маленькие датасеты.

## Датасеты

1. `anscombe.csv` — загруженный файл с квартетом Энскомба. Используется для обычной и робастной регрессии, а также как первый датасет для вероятностного программирования.
2. `iris_small.csv` — готовый датасет Iris из `sklearn`, взято по 30 строк каждого класса, всего 90 строк. Он нужен для логистической регрессии и softmax.
3. `toothgrowth.csv` — датасет R `ToothGrowth`, 60 наблюдений. Это единственный дополнительно взятый интернет-датасет для вероятностного программирования.

## Что лежит в графиках

- `01_coin_binomial.png` — биномиальное распределение для разных вероятностей успеха.
- `02_coin_posterior.png` — апостериорное распределение параметра монеты `θ`.
- `03_anscombe_bayes_lines.png` — четыре группы Энскомба с линиями регрессии.
- `04_robust_regression.png` — сравнение OLS, своего Huber-варианта и варианта из книги через Student-t.
- `05_hierarchical_regression.png` — пример частичного объединения групп в иерархической регрессии.
- `06_iris_binary_logistic.png` — бинарная логистическая регрессия на Iris.
- `07_iris_softmax_confusion.png` — softmax-классификация трех классов Iris.
- `08_*_ab_beta.png` — A/B-анализ через beta-binomial.
- `09_*_lift.png` — распределение относительного роста.
- `10_*_dirichlet_value.png` — Dirichlet-модель ожидаемой полезности.
- `11_*_mean_diff.png` — распределение разности средних для двух групп.

Подробная теория, обозначения и объяснение «что вообще происходит» находятся в файле `theory.md`.
