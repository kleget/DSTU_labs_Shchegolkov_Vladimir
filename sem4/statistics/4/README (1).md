# Байесовский анализ и вероятностное программирование на Python

Работа собрана как небольшой проект: код, данные, графики и отчет в Markdown.

## Как запускать

```bash
pip install -r requirements.txt
python run_all.py
```

После запуска:

- `figures/` — все графики;
- `results/` — таблицы с численными результатами;
- `data/` — исходные и подготовленные датасеты;
- `scripts/` — код по разделам.

## Что где находится

| Требование | Файл |
|---|---|
| Байесовский анализ, стр. 35-41: монета, Beta-Binomial | `scripts/01_coin_beta_binomial.py` |
| Байесовский анализ, стр. 101-114: простая линейная регрессия | `scripts/02_linear_regression_book.py` |
| Байесовский анализ, стр. 118-127: робастная и иерархическая регрессия | `scripts/03_robust_anscombe.py`, `scripts/04_hierarchical_regression.py` |
| Байесовский анализ, стр. 157-175: логистическая регрессия, softmax, LDA | `scripts/05_logistic_iris.py` |
| Вероятностное программирование, стр. 62-94: A/B, конфиденциальный опрос, Challenger | `scripts/06_prob_prog_book_examples.py` |
| Вероятностное программирование, стр. 231-249: A/B, Dirichlet, BEST, lift | `scripts/07_prob_prog_tips_ab.py` |

## Датасеты

- `anscombe.csv` — загруженный датасет квартета Энскомба, 44 строки. Используется для робастной регрессии и четырех графиков зависимостей.
- `tips_small.csv` — новый датасет меньше 100 строк: 80 строк из классического `tips`, сохранен локально, чтобы работа запускалась без интернета.
- `iris_ready.csv` — готовый датасет Iris из `sklearn`, создается скриптом для логистической регрессии.

## Важное замечание

В книгах примеры часто написаны через PyMC/PyMC3. Здесь код сделан проще и автономнее: основные вычисления выполнены через `numpy`, `pandas`, `scipy`, `matplotlib`, а PyMC не требуется. Смысл моделей сохранен: априорное распределение, правдоподобие, апостериорное распределение, прогнозы и графики.
