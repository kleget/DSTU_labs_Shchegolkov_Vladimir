# Проверка распределений: краткое объяснение

## 1. Распределение Пуассона

- **Когда используется:** для редких событий, подсчёта количества “сбоев”, “нестандартных изделий” и т.п.
- **Что делаем:** считаем параметр λ — среднее число событий.
- **Формула:**  
  P(X = m) = λ^m * e^(-λ) / m!
- **Зачем:** с помощью λ можно построить **теоретические частоты**, чтобы сравнить с фактическими.
- **Дальше:** сравниваем с наблюдаемыми n_i через критерий χ² (Пирсона) для проверки согласия.

---

## 2. Критерий Пирсона (χ²)

- **Когда используется:** чтобы проверить, подходит ли **выборка** под предполагаемое распределение.
- **Что делаем:**
  1. Считаем теоретические частоты nP_i по выбранной модели (Пуассон или нормальное распределение).  
  2. Если частоты < 5, объединяем интервалы, чтобы расчёт был корректным.  
  3. Считаем χ²:  
     χ² = Σ (n_i - nP_i)² / nP_i  
  4. Определяем **число степеней свободы**: r = k - 1 - s  
     - k = число групп после объединения  
     - s = число параметров, оценённых по выборке
  5. Сравниваем с χ² крит из таблицы при α = 0.05
- **Зачем:** если χ² эмпирическое < χ² крит → гипотеза не отвергается.

---

## 3. Критерий Колмогорова

- **Когда используется:** проверка нормальности **без объединения интервалов**.
- **Что делаем:**
  1. Строим **эмпирическую функцию распределения** F_n(x) = доля наблюдений ≤ x  
  2. Строим **теоретическую функцию распределения** F_0(x) для предполагаемой модели (например, нормальное распределение с x̄ и S)
  3. Считаем максимальное расхождение: D_n = max |F_n(x) - F_0(x)|
  4. Считаем λ = D_n * √n
  5. Сравниваем с критическим λ (1,36 при α = 0,05)
- **Зачем:** если λ < λ крит → гипотеза о нормальности не отвергается.

---

## ✅ Итог

- **Пуассон:** определяем среднее λ для редких событий.  
- **Пирсон (χ²):** проверяем согласие выборки с теоретическим распределением, объединяя маленькие интервалы.  
- **Колмогоров:** проверяем нормальность, используя максимум расхождения между эмпирической и теоретической функцией распределения.  
- Все методы дают числовую проверку: сравниваем эмпирическое значение с критическим → делаем вывод о гипотезе.
