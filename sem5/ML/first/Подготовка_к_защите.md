# Лабораторная работа: агломеративная кластеризация

## Цель работы

Реализовать на Python иерархическую агломеративную кластеризацию. Расстояние между объектами и центроидами кластеров вычисляется по Минковскому с параметром `p`. Ручной алгоритм сравнивается с библиотечной реализацией для того случая, где такое сравнение корректно: евклидово расстояние (`p = 2`).

По каждому из трёх наборов программа строит две диаграммы: дендрограмму и диаграмму рассеивания. Итого один запуск создаёт шесть графиков.

## Что находится в папке

| Файл | Назначение |
|---|---|
| `main.py` | Загрузка и стандартизация данных, ручная кластеризация, сравнение с SciPy, таблицы и графики. |
| `regions.csv` | 18 российских регионов и три экономических показателя. |
| `small_regions.csv` | Учебный набор из 6 регионов и двух показателей. Исходный файл в папке примера одногруппника не изменялся. |
| `iris.csv` | Новый реальный набор UCI Iris: 150 цветков и 4 измерения в сантиметрах. Столбец вида удалён и не участвует в кластеризации. |

UCI описывает Iris как 150 измерений четырёх параметров цветка. В файл лабораторной попали только числовые измерения и техническое имя объекта; столбец с видом удалён и не используется. Источник и условия использования: [UCI Machine Learning Repository — Iris](https://archive.ics.uci.edu/dataset/53/iris), лицензия CC BY 4.0.

## Теория

### Расстояние Минковского

Для двух объектов `x` и `y` с `m` признаками расстояние вычисляется так:

\[
d_p(x,y)=\left(\sum_{j=1}^{m}|x_j-y_j|^p\right)^{1/p}, \qquad p\ge 1.
\]

- При `p = 1` получаем манхэттенское расстояние: складываются модули разностей признаков.
- При `p = 2` получаем обычное евклидово расстояние.
- При других `p >= 1` программа также считает расстояние Минковского.

### Центроидная связь

Центроид кластера — вектор средних значений его признаков:

\[
c_C=\frac{1}{|C|}\sum_{x\in C}x.
\]

Расстояние между кластерами `A` и `B` — расстояние Минковского между их центроидами:

\[
D_p(A,B)=d_p(c_A,c_B).
\]

Это и есть используемый критерий слияния. На каждом шаге алгоритм выбирает пару кластеров с минимальным `D_p`, объединяет её, пересчитывает центр нового кластера и матрицу расстояний. Процесс начинается с одного объекта в каждом кластере и продолжается, пока не останется один.

`R_t` — матрица расстояний между кластерами, существующими перед очередным слиянием. В программе для небольших наборов она сохраняется после каждого шага. В нижней части матрицы стоят те же значения, что и в верхней; на диагонали — нули.

### Стандартизация признаков

Перед вычислением расстояний программа применяет стандартизацию каждого признака:

\[
z=\frac{x-\mu}{\sigma}.
\]

После неё среднее признака равно нулю, а стандартное отклонение — единице. Это важно, потому что величины измеряются в разных единицах и диапазонах: без стандартизации признак с большими числами мог бы почти полностью определять расстояние. Стандартизируются признаки, но не имена регионов и объектов.

Для Iris кластеризация использует все четыре стандартизированных признака. Трёхмерный график показывает только `Sepal_length_cm`, `Petal_length_cm` и `Petal_width_cm`, чтобы его можно было нарисовать на плоскости экрана. Это проекция результата, а не повторная кластеризация только по трём признакам.

### Ручная и библиотечная реализации

В `manual_centroid_linkage` реализованы поиск ближайшей пары, объединение и пересчёт расстояний между новыми центроидами. При равных расстояниях выбирается пара кластеров с меньшими внутренними номерами, чтобы результат был воспроизводим.

Для проверки начальная матрица ручных расстояний сравнивается с `scipy.spatial.distance.pdist` для введённого `p`. Полная библиотечная иерархия строится функцией `scipy.cluster.hierarchy.linkage` с `method="centroid"` и евклидовым расстоянием. [Документация SciPy](https://docs.scipy.org/doc/scipy/reference/generated/scipy.cluster.hierarchy.linkage.html) определяет centroid, median и Ward для евклидовой метрики; передавать в centroid расстояние Минковского с `p = 1` как будто это тот же алгоритм некорректно. Поэтому при `p = 1` программа показывает два результата: проверку начальной матрицы при `p = 1` и сравнение полных иерархий ручного алгоритма и SciPy при `p = 2`. При запуске с `p = 2` полное сравнение относится к текущим графикам.

В таблице сравнения оцениваются:

- согласие разбиений на `k` кластеров по парам объектов (названия номеров кластеров могут отличаться, поэтому сравниваются отношения «в одном кластере / в разных»);
- максимальная разница высот слияний ручного и библиотечного вариантов при `p = 2`;
- максимальная разница элементов начальной матрицы с `scipy.pdist` при выбранном `p`.

Это метод центроидов, а не Ward: в лабораторной не используется критерий минимизации внутрикластерной суммы квадратов.

## Установка и запуск

Откройте PowerShell в каталоге `sem5/ML/first` и выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install numpy pandas scipy matplotlib
```

Запуск с запросом параметров в терминале:

```powershell
python main.py
```

На вопросы программы введите `p` (для защиты удобно показать `1`, затем `2`) и число кластеров для раскраски графиков. По умолчанию выбрано `k=2`, как в примере преподавателя.

Либо передайте параметры сразу:

```powershell
python main.py --p 2 --k 2
python main.py --p 1 --k 2
```

После каждого запуска сохранится шесть PNG-графиков. В обычном режиме они также откроются в окнах Matplotlib; 3D-диаграмму можно вращать мышью. Если нужно только сохранить файлы:

```powershell
python main.py --p 2 --k 2 --no-show
```

Если PowerShell запрещает активацию виртуального окружения, установите зависимости и запустите программу напрямую:

```powershell
.\.venv\Scripts\python.exe -m pip install numpy pandas scipy matplotlib
.\.venv\Scripts\python.exe main.py --p 2 --k 2
```

## Что создаётся при запуске

Результаты сохраняются рядом со скриптом в `results`:

- `results/p_2/` или `results/p_1/`: по две картинки на набор — дендрограмма и диаграмма рассеивания; CSV со слияниями, итоговыми кластерами и сводным сравнением.
- `results/matrices/`: отдельные CSV-файлы матриц `R_t` для двух небольших наборов.
- На диаграмме рассеивания каждый кластер имеет свой цвет. Число кластеров задаётся через `k`; оно выбирает срез полной иерархии для показа.
- Для Iris дендрограмма сокращена до последних слияний, иначе подписи 150 объектов перекрывали бы друг друга.

### Итог контрольного запуска

Сохранённый запуск `p=2, k=2` даёт следующие размеры кластеров:

| Набор | Объектов | Признаков | Размеры двух кластеров |
|---|---:|---:|---:|
| Регионы | 18 | 3 | 16 и 2 |
| Учебные регионы | 6 | 2 | 3 и 3 |
| Iris | 150 | 4 | 50 и 100 |

Ручная реализация и SciPy дали одинаковые разбиения на всех трёх наборах (`100%` согласия пар). Максимальное различие высот слияний из-за округления чисел с плавающей точкой не превышает `9·10⁻¹⁶`. Эти цифры можно показать в `results/p_2/comparison_summary.csv`.

## Короткие ответы на вопросы

**Что означает `p`?** Показатель в метрике Минковского. `p=1` — сумма модулей разностей признаков; `p=2` — евклидово расстояние.

**Почему признаки стандартизируются?** Иначе большие масштабы измерения могут непропорционально повлиять на расстояние.

**Что такое центроид?** Покомпонентное среднее значение признаков всех объектов кластера.

**Как получается нужное число кластеров?** Алгоритм строит всю иерархию до одного кластера. Для графика берётся состояние после `n-k` слияний.

**Почему результаты могут отличаться от SciPy при `p=1`?** Встроенный метод SciPy `centroid` определён для евклидовых расстояний. Для произвольного `p` ручная реализация каждый шаг пересчитывает расстояния между центрами по заданной формуле; SciPy centroid нельзя считать эквивалентным вариантом для `p=1`.

**Почему кластеры в графике трёхмерные для части наборов?** Для регионального набора показаны все три признака; для Iris выбран видимый срез по трём признакам. Расчёт кластеров в Iris при этом использует все четыре.

**Чем центроидный метод отличается от Ward?** Центроидный метод объединяет ближайшие средние векторы кластеров. Ward выбирает слияние по приросту внутрикластерной дисперсии. Это разные критерии.

**Почему на дендрограмме Iris не видны все подписи объектов?** Там 150 строк, поэтому дерево свёрнуто до последних 30 групп, чтобы слияния можно было прочитать.
