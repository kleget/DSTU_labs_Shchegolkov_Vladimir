# Лабораторная № 2. Парный дискриминантный анализ

Цель — определить класс нового объекта по числовым измерениям. Классы обучающих объектов известны. Для предприятий класс 1 означает передовое предприятие, для крабов — оранжевую цветовую форму.

## Запуск

```powershell

```

Для нового компьютера создайте окружение командой `py -3.11 -m venv .venv`, затем выполните `.\.venv\Scripts\python.exe -m pip install numpy pandas matplotlib scikit-learn`. Флаг `--no-show` позволяет сохранить графики без открытия окна.

## Как объяснить десять шагов

1. Разделить исходные измерения на $X_1$, $X_2$ и $X_0$. Строки — объекты, столбцы — признаки. В $X_0$ находятся объекты для классификации.
2. Найти вектор средних признаков $m_j$ для каждого обучающего класса.
3. Вычесть $m_j$ из каждой строки своего класса. Для полученной матрицы $Z_j$ вычислить выборочную ковариацию $S_j=Z_j^T Z_j/(n_j-1)$. На диагонали находятся дисперсии, вне диагонали — ковариации признаков.
4. Объединить матрицы с весами по числу степеней свободы: $S=((n_1-1)S_1+(n_2-1)S_2)/(n_1+n_2-2)$.
5. Проверить ранг и обратить $S$. При полной линейной зависимости признаков обратной матрицы нет. Число обусловленности и VIF помогают обнаружить близость к зависимости даже при полном ранге.
6. Найти направление разделения $A=S^{-1}(m_1-m_2)$. Разность средних задаёт направление, а обратная ковариация учитывает разброс и совместное изменение признаков.
7. Для каждого обучающего объекта вычислить одно число $F(x)=x^T A$.
8. Найти среднее $F$ внутри каждого класса.
9. Взять порог $c$ посередине между этими двумя средними. Такой выбор соответствует равным априорным вероятностям классов и равной цене двух типов ошибок.
10. Вычислить $F$ для каждого тестового объекта. Если $F>c$, выбирается класс 1. При $F\le c$ выбирается класс 0. Промежуточные вычисления ведутся с полной точностью, матрицы в терминале округляются до трёх знаков.

## Эксперимент с крабами

В [crabs.csv](crabs.csv) приведены измерения 200 крабов *Leptograpsus* из Фримантла (Западная Австралия). Кэмпбелл и Махон опубликовали исследование в 1974 году. В каждой цветовой форме по 50 самцов и 50 самок. Задача — предсказать синюю (0) или оранжевую (1) форму по геометрии тела. В CSV переведены заголовки и категории, сохранены все исходные строки и измерения. [Словарь признаков MASS и ссылка на публикацию](https://stat.ethz.ch/R-manual/R-devel/library/MASS/html/crabs.html) · [Исходная таблица](https://vincentarelbundock.github.io/Rdatasets/csv/MASS/crabs.csv)

У крупных крабов одновременно увеличиваются несколько промеров. Для сравнения формы вычисляем три признака: размер лобной доли, заднюю ширину и толщину тела в процентах от ширины панциря. Например, для первого краба относительная толщина равна $100\cdot 7/19=36{,}84$ %. Делитель берётся из той же строки. Номер записи, номер в группе, пол, длина панциря и целевая метка не входят в матрицу признаков. Цвет нужен только при обучении и оценке. В среднем толщина тела составляет 36,11 % ширины панциря у синей формы и 40,59 % у оранжевой.

Программа проверяет наличие меток и положительных конечных промеров. Классы стратифицируются, seed равен 42. Средние, ковариации и порог вычисляются заново только по обучающей части. Библиотечный LDA получает те же строки, признаки и априорные вероятности.

На защите откройте `results/crabs.png`. На трёх панелях по горизонтали отложен исходный номер краба, по вертикали — $F-c$. Горизонтальная линия проходит через ноль. Круг — обучающий объект, треугольник — прогноз на тесте, красный крест — ошибка. Панель 90/10 содержит всего 20 тестовых объектов, поэтому одна ошибка меняет Accuracy сразу на 5 процентных пунктов. Для 70/30 одна ошибка меняет её примерно на 1,67 пункта.

В матрице ошибок строки отвечают фактическому классу, столбцы — прогнозу. **FP** — особь синей формы ошибочно отнесена к оранжевой, **FN** — особь оранжевой формы ошибочно отнесена к синей. Accuracy — доля верных ответов, Precision — доля особей оранжевой формы среди предсказанных оранжевых, Recall — доля верно распознанных оранжевых особей среди всех оранжевых. F1 — гармоническое среднее Precision и Recall. Файлы `results/crabs_*_test.csv` содержат все прогнозы и позволяют проверить конкретную ошибку по номеру.

## Учебный пример преподавателя

<!-- Предприятия проверяются отдельно по контрольным значениям методички. -->

В [enterprises.csv](enterprises.csv) записаны все 12 предприятий из таблицы преподавателя. Три признака по порядку — основные фонды, численность и прибыль. Метки четырёх передовых — 1, пяти отстающих — 0, у трёх неизвестных поле класса пустое. При обычном запуске сначала рассчитывается этот пример, затем выполняются эксперименты с крабами. Можно запустить любой набор отдельно:

```powershell
.\.venv\Scripts\python.exe main.py --dataset enterprises
.\.venv\Scripts\python.exe main.py --dataset crabs
```

Получены коэффициенты $(0{,}156720; 3{,}594781; -1{,}291500)$, средние дискриминантные значения 53,293 и 10,458, порог 31,87564. У предприятия № 10 значение 26,589 ниже порога — отстающее. У № 11 и № 12 значения 34,407 и 52,160 выше порога — оба передовые. Код сравнивает вычисленные величины с контрольными после классификации.

## Что показали эксперименты

| Обучение / тест | Число крабов в тесте | TN | FP | FN | TP | Верно |
|---|---:|---:|---:|---:|---:|---:|
| 70/30 | 60 | 30 | 0 | 0 | 30 | 60 |
| 80/20 | 40 | 20 | 0 | 0 | 20 | 40 |
| 90/10 | 20 | 10 | 0 | 0 | 10 | 20 |

На этих фиксированных разбиениях ручной алгоритм и sklearn дали одинаковые прогнозы, Accuracy, Precision, Recall и F1 равны 1. Увеличение обучающей доли здесь не изменило наблюдаемую точность. На новых наблюдениях ошибки возможны: граница LDA линейна, а разброс признаков описан одной общей ковариацией. У трёх обучающих выборок максимальный внутриклассовый VIF меньше 1,24. В исходных 200 строках нет пропусков по выбранным признакам и полных дубликатов. По правилу 1,5 межквартильного размаха ни у одного из трёх относительных признаков нет значений за границами.

**Как влияет предобработка (п. 1.24).** Для контрольного сравнения обучили библиотечный LDA на тех же строках с теми же вероятностями классов, передав три исходных промера в миллиметрах. Получилось 42/60, 32/40 и 17/20 верных ответов соответственно. После деления каждого промера на ширину панциря той же особи получилось 60/60, 40/40 и 20/20. Меняется биологический смысл признака: например, толщина 7 мм для маленького и крупного краба соответствует разным пропорциям тела. Для воспроизведения контрольного сравнения в функции `crabs` замените выражение `100 * measurements[:, :3] / measurements[:, 3:4]` на `measurements[:, :3]` в копии программы.

**Как объяснить ошибки и границу.** В основном эксперименте FP = FN = 0 на всех трёх тестах. Равный баланс классов делает Accuracy удобной сводкой. При сильном дисбалансе высокий результат по Accuracy возможен даже при пропуске редкого класса, поэтому отдельно проверяются Precision и Recall. Достоинство LDA — решение можно проверить по одному числу $F-c$ и трём коэффициентам. Изогнутая граница между классами или сильно разный разброс внутри классов могут ухудшить качество. Для увеличения участка графика используйте лупу интерактивного окна Matplotlib.
