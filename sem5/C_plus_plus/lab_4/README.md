# Лабораторная № 4. Файлы и обработка исключений — вариант 1

Условия взяты из «МетУк-Пр-4-Файлы (1).pdf»: общие требования — страницы 13–14, вариант 1 — страница 14. Номера страниц указаны от начала PDF.

Если работаешь с файлами впервые, сначала прочитай разделы 1–4 в [THEORY.md](THEORY.md), затем запусти программу по инструкции ниже. Остальная теория объясняет бинарные файлы, динамический массив и исключения, которые нужны для третьего задания.

## Что требуется

1. Ввести целое `K`, где `0 < K < 10`, и получить последние `K` строк текстового файла. Неверное `K` запрашивать повторно. Если строк меньше `K`, скопировать все. Если файл пуст, сообщить об этом.
2. Записать в новый файл все символы исходного текста без повторений, в порядке первого появления. Учитывать пробелы и знаки препинания.
3. Хранить сведения о путёвках: Ф.И.О., кафедру (группу, отдел), номер путёвки, период пребывания, название санатория, примечание. Выводить сотрудников по заданному санаторию и периоду пребывания.

Общие требования методички тоже реализованы: классы, диалог с пользователем, проверка открытия файлов, исключения. Для задания 3 есть структура, динамический массив, добавление, удаление, вывод, сохранение и загрузка в бинарном режиме, чтение отдельной записи по номеру.

Для `K` принимаются **только значения 1–9**, как следует из строгого неравенства в условии. Числа `0`, `10`, `2.5` и текст отклоняются.

## Как запустить

Используется тот же GCC из MSYS2 UCRT64, что и для лабораторной № 3: `C:\msys64\ucrt64\bin\g++.exe`.

Из корня репозитория в PowerShell выполни одну команду:

```powershell
powershell -ExecutionPolicy Bypass -File .\sem5\C_plus_plus\lab_4\run.ps1
```

Скрипт перейдёт в папку лабораторной, соберёт `main.cpp` и запустит программу. Созданные файлы будут лежать в `lab_4`. Из папки самой лабораторной команда короче:

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

Можно собрать вручную, как лабораторную № 3. Из корня репозитория:

```powershell
Set-Location .\sem5\C_plus_plus\lab_4
$env:Path = "C:\msys64\ucrt64\bin;" + $env:Path
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o lab4.exe
if ($LASTEXITCODE -eq 0) { .\lab4.exe }
```

Здесь нужен только один `.cpp`. После изменения кода пересобери программу. Для последующих запусков уже собранной программы в том же терминале достаточно `.\lab4.exe`.

При ручном запуске текущей папкой должна быть `lab_4`: относительно неё программа ищет исходные файлы и создаёт результаты. Скрипт устанавливает эту папку сам. Команды рассчитаны на уже установленный MSYS2 по указанному пути.

## Задание 1: последние строки

Введи по очереди, нажимая Enter после каждой строки:

```text
1
text.txt
2
0
```

Это выбор задания, имя исходного файла, значение `K` и выход. В `last_lines.txt` получится:

```text
Четвёртая строка!
Last line.
```

Метод `TextFile::copyLastLines`:

1. Открывает исходный файл и считает строки с помощью `getline`.
2. Сбрасывает состояние конца файла через `clear()` и возвращается в начало через `seekg(0)`.
3. Читает строки повторно. Записывает строку, если её индекс `i >= count - k`.
4. Проверяет запись результата. Для пустого исходного файла выводит сообщение и создаёт пустой результат.

При пяти строках и `K = 2` условие имеет вид `i >= 3`. Индексы начинаются с нуля, поэтому копируются четвёртая и пятая строки. Если `K` больше количества строк, `count - k` отрицательно, и подходят все строки.

Пустая строка тоже считается строкой. Обычный перевод строки после последней непустой строки сам по себе дополнительной пустой строки не создаёт.

## Задание 2: символы без повторений

Введи:

```text
2
text.txt
0
```

Открой `unique_chars.txt` в редакторе. Например, для исходного текста:

```text
аб а!
б?
```

результат будет:

```text
аб !
?
```

Метод `TextFile::uniqueCharacters` читает символ, ищет его в строке `seen` и записывает, только если его там ещё нет. Затем добавляет символ в `seen`. Поэтому сохраняется порядок первого появления.

Используй **текст в UTF-8**. Русская буква занимает несколько байтов: небольшой цикл с `peek()` собирает эти байты в один символ. Его работа разобрана в [теории](THEORY.md#4-символы-строки-и-utf-8).

Пробел, табуляция и перевод строки тоже учитываются. Перевод строки появляется в результате один раз, в месте первого появления. Дополнительный перевод строки в конец результата программа не добавляет, чтобы не создавать повторный символ. Одинаковыми считаются символы с одинаковой записью в UTF-8; регистр учитывается.

## Задание 3: путёвки

| Пункт | Действие |
| --- | --- |
| 3 | Ввести и добавить одну путёвку в массив |
| 4 | Удалить запись по её порядковому номеру в массиве |
| 5 | Вывести весь массив |
| 6 | Сохранить весь массив в `vouchers.txt` |
| 7 | Загрузить весь массив из `vouchers.txt` |
| 8 | Прочитать и показать одну запись прямо из файла |
| 9 | Вывести Ф.И.О. сотрудников в указанном санатории |
| 10 | Вывести Ф.И.О. сотрудников с указанным периодом |
| 0 | Завершить программу |

Пример добавления и сохранения одной путёвки:

```text
3
Иванов Иван Иванович
ПОВТ
101
01.06.2026-14.06.2026
Дон
Без примечаний
5
6
0
```

После перезапуска введи `7`, чтобы загрузить сохранённый список, затем `5`, чтобы увидеть его. Изменения массива сохраняются пунктом `6`; при сохранении старое содержимое файла заменяется текущим списком. Пункт `7` заменяет текущий массив содержимым файла.

Для поиска по санаторию введи `9`, затем `Дон`. Для поиска по периоду введи `10`, затем `01.06.2026-14.06.2026`. Сравнение выполняется по точному совпадению строк, с учётом регистра и пробелов. Период хранится одной строкой в указанном формате и сравнивается целиком.

**Порядковый номер записи и номер путёвки — разные вещи.** Если первой добавлена путёвка № 101, у неё порядковый номер `1`. Для чтения её из сохранённого файла выбери `8` и введи `1`. При этом весь файл в массив не загружается. Удаление тоже использует порядковый номер, показанный пунктом `5`; после удаления следующие номера сдвигаются.

### Как устроены данные

`Voucher` — структура одной записи. Текстовые поля представлены массивами `char`, а номер путёвки — числом `int`. Все записи имеют одинаковый размер `sizeof(Voucher)`, что позволяет сразу перейти к нужной записи файла.

`VoucherList` — класс, который хранит:

```cpp
Voucher* data;
int count;
```

`data` указывает на динамический массив, `count` хранит число используемых элементов.

| Метод | Что делает |
| --- | --- |
| `add` | Создаёт массив на один элемент больше, копирует записи, добавляет новую |
| `remove` | Сдвигает записи после удаляемой на одну позицию влево, уменьшает `count` |
| `printAll` | Выводит используемые элементы массива |
| `save` | Записывает структуры одну за другой через `write` |
| `load` | Узнаёт размер файла, выделяет массив и считывает структуры через `read` |
| `readOne` | Через `seekg` переходит к записи и считывает только её |
| `findSanatorium`, `findPeriod` | Перебирают массив и выводят Ф.И.О. при совпадении поля |

При удалении выделенная память остаётся прежней, но последний элемент уже не учитывается. Это позволяет обойтись сдвигом элементов. При добавлении выделяется новый массив, а при завершении работы деструктор освобождает память.

В текстовых полях предусмотрено место для завершающего нуля. Поля по 100 байтов принимают до 99 байтов текста, примечание — до 199. Русская буква обычно занимает два байта в UTF-8. Пустое поле или слишком длинный текст запрашивается заново; вместо пустого примечания можно ввести `-`.

## Ошибки и исключения

Если исходный файл отсутствует или его нельзя открыть, программа выводит сообщение и заканчивает работу, как требует методичка. Таким же образом обрабатываются ошибки записи и чтения бинарного файла.

В методе возникает `throw runtime_error(...)`. В `main` один блок `catch` получает ошибку, выводит её текст через `what()` и завершает программу с кодом `1`. Успешный выход через пункт `0` имеет код `0`.

Файлы результатов перезаписываются при повторном выполнении соответствующего задания. Проверка `checkOutput` не позволяет использовать один и тот же файл одновременно как исходный и результирующий: для этого сравниваются сами файлы через `filesystem::equivalent`.
