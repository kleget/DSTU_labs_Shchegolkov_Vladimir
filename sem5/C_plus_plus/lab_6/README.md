# Лабораторная № 6. Статические поля и дружественные функции

Методичка «МетУк_Пр_2_Статические_поля_и_методы_Друж_функции», общие требования на страницах 5–6, вариант на странице 6. В таблице 25 заданий. По кругу номер 27 соответствует варианту 2 (`27 − 25 = 2`).

Класс `Patient` хранит возраст (`int`) и диагноз (`char*`). Метод `Diagnose` задаёт или заменяет диагноз, а `checkOut` удаляет его при выписке. Вся программа находится в [main.cpp](main.cpp). В `main()` последовательно выполняются примеры из методички с фиксированными данными.

## Сборка и запуск

Выполни команды из корня репозитория в PowerShell. Инструкция по установке GCC из MSYS2 UCRT64 находится в разделе 7 [README лабы № 3](../lab_3/README.md).

```powershell
Set-Location .\sem5\C_plus_plus\lab_6
$env:Path = "C:\msys64\ucrt64\bin;" + $env:Path
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o lab6.exe
if ($LASTEXITCODE -eq 0) { .\lab6.exe }
```

Если терминал уже открыт в `lab_6`, начни со строки с `PATH`. После запуска программа сама напечатает ход проверки. Повторно запустить уже собранный файл можно командой `.\lab6.exe` из той же папки.

## Как объяснить код

| Часть | Что делает |
| --- | --- |
| `static int objectCount` | Общее поле класса. Конструктор прибавляет единицу, деструктор вычитает её |
| `int Patient::objectCount = 0;` | Определяет и инициализирует статическое поле вне класса |
| `Patient::getObjectCount()` | Статический метод, который можно вызвать через имя класса, даже когда объектов ещё нет |
| `Patient::create` и `Patient::destroy` | Статические методы класса. Имеют доступ к закрытым конструктору и деструктору и вызывают их через `new` и `delete` |
| `createPatient` и `destroyPatient` | Внешние функции с тем же назначением. Объявление с `friend` даёт им доступ к закрытому конструктору и деструктору |
| `printPatient` | Дружественная функция, которая читает закрытые возраст и диагноз через ссылку на пациента |
| `demonstrateObjectCount` | Создаёт обычный локальный массив без `new`. Метод класса имеет доступ к закрытым конструктору и деструктору. Когда функция заканчивается, оба элемента автоматически уничтожаются |

`Diagnose(const char* text)` принимает строку для чтения. Для хранения функция создаёт собственную копию. `strlen(text) + 1` учитывает завершающий нулевой символ, а `strcpy` переносит текст в выделенный массив. После копирования `clearDiagnosis()` освобождает прежний буфер через `delete[]`. Эту закрытую функцию вызывают также при выписке и уничтожении пациента. `nullptr` означает, что диагноз отсутствует.

В коде удалены конструктор копирования и оператор присваивания. Иначе обычное копирование указателя привело бы к тому, что два пациента пытались бы освободить один и тот же буфер.

Для защиты объясни, почему счётчик один на весь класс, какой код запускается при уничтожении массива и почему внешняя функция `printPatient` может обращаться к полям `private`.
