# Лабораторная № 5. Введение в ООП

Методичка «МетУк-Пр-1-Введение в ООП», общие требования на страницах 5–6, вариант на странице 6. В таблице 25 заданий. По кругу номер 27 соответствует варианту 2 (`27 − 25 = 2`).

Программа хранит сведения о поступивших студентах. Для каждого записывает фамилию, потребность в общежитии, работу учителем и стаж этой работы, оконченное учебное заведение и изученный язык. Затем она печатает все записи и четыре результата из задания.

| Что требуется | Где смотреть в [main.cpp](main.cpp) |
| --- | --- |
| Класс с закрытыми полями и методами чтения и записи | `Student`, методы `get…` и `set…` |
| Несколько конструкторов, в том числе копирования | `Student()`, конструктор со всеми полями и `Student(const Student&)` |
| Заполнение коллекции и вывод её элементов | `readStudents`, `printStudents` и `Student::print` |
| Число нуждающихся в общежитии | `countDormitoryApplicants` |
| Работавшие учителем два года и более | `printTeachers` |
| Выпускники педучилища | `printTeachingSchoolGraduates` |
| Списки языковых групп | `printLanguageGroups` |

## Сборка и запуск

Открой PowerShell в корне репозитория. Команды рассчитаны на GCC из MSYS2 UCRT64. Если GCC ещё нужно установить, смотри раздел 7 в [README лабы № 3](../lab_3/README.md).

```powershell
Set-Location .\sem5\C_plus_plus\lab_5
$env:Path = "C:\msys64\ucrt64\bin;" + $env:Path
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o lab5.exe
if ($LASTEXITCODE -eq 0) { .\lab5.exe }
```

Если терминал уже открыт в `lab_5`, начни со строки с `PATH`. В этом же терминале для повторного запуска достаточно `.\lab5.exe`. После изменения кода запусти сборку ещё раз.

Вводи по одному ответу на строку. Для ответов «да» и «нет» используй `1` и `0`. Если студент работал учителем, укажи стаж в полных годах. Иначе программа сама запишет ноль и сразу спросит про образование. Для отбора выпускников введи `педучилище` строчными буквами. Язык пиши одинаково для всех участников одной группы, поскольку группировка сравнивает введённые названия посимвольно.

## Как объяснить код

1. `class Student` описывает тип одной записи. Объект `student` содержит собственные значения полей. Метки `private` и `public` управляют доступом. Например, фамилию извне читают через `getSurname()` и меняют через `setSurname(...)`.
2. Конструктор `Student(...)` заполняет поля через список инициализации после двоеточия. Короткий `Student()` вызывает этот же конструктор с начальными значениями. `= default` у конструктора копирования просит компилятор скопировать каждое поле. Вызов `students.push_back(student)` создаёт копию записи в векторе.
3. `std::vector<Student>` хранит коллекцию и увеличивается по мере добавления записей. `readStudents` получает вектор по ссылке и заполняет его. Функции вывода получают `const std::vector<Student>&`, поэтому работают с той же коллекцией и могут только читать её.
4. `std::cin >>` читает числа, а `std::getline` читает строку целиком. `std::ws` перед `getline` убирает оставшийся после числового ввода перевод строки. `main()` завершает программу с кодом 1, если чтение записи не удалось.
5. При отборе учителей условие `workedAsTeacher && experience >= 2` требует сразу двух признаков. Знак `>=` включает стаж ровно два года.
6. В языковой группировке ключ `std::map` — язык, значение — вектор фамилий. Вызов `groups[student.getLanguage()].push_back(student.getSurname())` находит или создаёт группу и добавляет в неё фамилию.

Для защиты попробуй без подсказки написать поля класса и цикл, который считает нуждающихся в общежитии. Объясни, когда вызывается конструктор копирования и почему функции выборки принимают вектор по константной ссылке.
